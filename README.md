# Influencer Clash — Windows

Versión jugable para Windows de 64 bits. Este repositorio contiene el ejecutable y toda la carpeta `Juego` necesaria para ejecutarlo.

## Descargar y jugar

1. Instala Git y Git LFS.
2. Clona este repositorio y ejecuta `git lfs pull` dentro de la carpeta clonada.
3. Abre `Juego/InfluencerClash.exe` en Windows. Mantén `InfluencerClash_Data` y las demás dependencias junto al `.exe`.

`Juego/InfluencerClash_Data/resources.assets` se almacena mediante Git LFS por su tamaño. El juego se compiló con Unity 6.6 y no se ejecutó después de la compilación.
