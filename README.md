# Influencer Clash — Windows

Versión jugable para Windows de 64 bits. Este repositorio contiene el ejecutable, la carpeta `Juego` completa y dos archivos ZIP en `Descargas/`:

- `Paquete_InfluencerClash_2026-11-11.zip`: juego compilado, manual y evidencias.
- `Proyecto_Unity_Influencers_clash.zip`: proyecto editable para Unity 6.6 (6000.6.6f1).

## Descargar y jugar

Para descargar los ZIP desde GitHub, abre cada archivo en `Descargas/` y usa **Download**. Para clonar el repositorio completo:

1. Instala Git y Git LFS.
2. Clona este repositorio y ejecuta `git lfs pull` dentro de la carpeta clonada.
3. Extrae el ZIP del juego y abre `Juego/InfluencerClash.exe` en Windows. Mantén `InfluencerClash_Data` y las demás dependencias junto al `.exe`.

Para abrir el proyecto editable, extrae su ZIP y añade la carpeta `Influencers clash` en Unity Hub. Unity regenerará `Library` y `Temp` al abrirlo.

Los archivos grandes, incluidos ambos ZIP, se almacenan mediante Git LFS. El juego no se ejecutó después de la compilación.
